## 1. 已实现

| 内容 | 实现与边界 |
|---|---|
| 后端模块 | 新增 `backend/ruoyi-exam`，接入父 POM 与 `ruoyi-admin`；没有引入 AI、POI 或 PDFBox 业务依赖 |
| 功能开关 | `EXAM_ENABLED=false` 为默认值；关闭时无考试 Repository/Service/Worker Bean，能力查询明确返回关闭 |
| 数据库任务 | `exam_task` DDL；幂等唯一键、条件领取、运行代次、60 秒租约、15 秒心跳、取消与受限重试 |
| 安全任务 | 当前仅有 `SYSTEM_CHECK`，用于验证任务链路，不调用模型、不读上传文件、不返回“出题成功” |
| 所有者边界 | 列表只显示当前用户任务；详情/取消/重试检查所有者或明确管理员权限；后台重新读取用户状态和菜单权限 |
| 并发与恢复 | 2 个工作线程，无内存排队，满载任务留在 DB；过期自检可重排，未知任务类型不自动重放 |
| HTTP 接口 | `/exam/capabilities`、任务分页/详情、自检提交、取消与重试；服务端生成 ID，响应 ID 为字符串 |
| 任务中心页面 | 关闭/未就绪/Worker 暂停提示、状态筛选、详情、取消/重试、有界轮询；离开/隐藏页面暂停轮询 |
| 私有存储原语 | 随机 key、独立根路径、拒绝公开目录重叠、10 MB 上限、失败时只清理本次半成品；目前没有挂接上传/下载接口 |
| 操作审计 | 提交、取消、重试使用既有操作日志注解；不保存完整请求/响应内容 |

新增菜单 SQL 使用自增 ID，不覆盖已有菜单或角色授权；普通角色需管理员明确授权。当前只播种任务中心，不生成尚未实现的资料库、题库或试卷入口。

## 2. 本轮设计细化

- 持久任务先采用 `JdbcTemplate` 的显式条件 SQL，便于核对并发更新与租约条件；复用既有 DataSource，不引入新队列/数据库。未来题库等领域仍可按项目习惯使用 MyBatis。
- 当前 `exam_task.id` 使用 MySQL 自增主键，沿用仓库既有模式；浏览器始终收到字符串 ID。此前“服务端生成 BIGINT”的设计在本表具体落实为数据库生成，不新增分布式 ID 依赖。
- 本轮只实现一个任务主体，不提前建立未使用的资料、试卷、AI 调用日志表。`PARTIAL_SUCCESS`、子任务、逐槽位生成及费用不确定确认流程需在接入相应业务时补齐。
- 自检重试通过 `expectedRevision` 的数据库条件更新防重复，每个任务最多运行 3 次；不能直接复用为付费 AI 重试。
- `EXAM_PRIVATE_ROOT` 是后续文件模块的配置预留；当前存储原语仅由测试直接验证，尚未注册为文件服务，不应理解为已开放安全文件上传。

## 4. 在隔离开发环境启用

1. 先备份并确认目标是开发/测试数据库。检查 `sys_menu` 的根路径 `exam` 和 `exam:task:*` 权限是否已被其他功能使用；有冲突先评审。
2. 在数据库客户端连接指定测试库，顺序执行 [任务表 SQL](../sql/exam_schema.sql) 和 [菜单 SQL](../sql/exam_menu_seed.sql)。不要执行 `ry_base.sql` 重建现有库。
3. 菜单脚本末尾返回根菜单和任务菜单 ID，两者必须非空；重复执行不会覆盖既有角色授权。脚本应单连接串行执行，尚未在实际 MySQL 验证。
4. 启动后台时设置 `EXAM_ENABLED=true`；`EXAM_WORKER_ENABLED=true` 为默认。若仅检查接口和排队，可设 Worker 为 false。
5. 用管理员为测试角色授权任务中心及所需按钮，重新登录/刷新权限，再进入“智能命题 → 任务中心”。点击“运行基础自检”应看到排队/执行/完成，不会生成题目。

PowerShell 环境变量示例（只影响当前终端启动的进程，不会自动执行迁移）：

```powershell
$env:EXAM_ENABLED = 'true'
$env:EXAM_WORKER_ENABLED = 'true'
```

此处没有要求提供模型密钥。资料外发授权和模型费用配置仍属于后续业务门禁。

关闭时设 `EXAM_ENABLED=false` 并重启应用，保留任务表和记录；禁止删库回退。重启后过期自检租约会被恢复；未确认是否有副作用的未知任务只进入 `NEEDS_CONFIRMATION`，不直接再次执行。

## 5. 可复现命令

在 `backend/`，使用 Java 17：

```powershell
mvn -o -B -pl ruoyi-exam -am test
mvn -o -B -DskipTests package -pl ruoyi-admin -am
```

在 `frontend/`，使用 Node 20+ 和已安装的锁定依赖：

```powershell
npm run test:exam
npm run build:prod
```

本轮前端使用已有 `node_modules` 直接执行相同 Node 测试入口与 Vite 生产构建，没有额外安装依赖。离线 Maven 依赖来自本机缓存；新环境需先准备依赖。
