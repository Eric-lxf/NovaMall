# 智能命题 MVP 开发与验证记录

日期：2026-09-03。分支：`codex/ai-exam-mvp`。

当前结论：核心命题闭环已通过本地真实 MySQL/JWT、Docker 文档导出和浏览器写入联调，**仍不是已经完成真实模型质量评估或可以直接上线的成品**。没有合并、推送、生产迁移、真实资料外发或付费模型调用。P0/P1 文档保留为历史记录；最新状态以本文为准。

## 已实现的功能

| 环节 | 交付及边界 |
|---|---|
| 资料 | 粘贴文本、UTF-8 TXT、隔离 DOCX/文本 PDF 解析任务；私有原件、版本、行/页/段落/表格位置；人工确认可用片段和独立外发授权；新版本/停用阻断旧依据正式使用 |
| 知识点 | 全部选定片段按最多 16000 字分批抽取，逐批成功/失败；手动新建、编辑、确认、停用、合并为新候选，原记录保留 |
| 要求与蓝图 | 本地自然语言辅助识别明确数字要求，展示歧义后人工填入；对象、题型、题数、分值、时长、难度、认知层级、解析要求；服务端校验和冻结快照 |
| 四类题目 | 单选、多选、判断、简答；逐槽位 AI 生成、严格字段/引用校验、最多一次预算内格式修复；题干完全重复阻断，同任务内字符二元组相似度提醒；手工新版本、明确选择槽位重做 |
| 质量门禁 | 不给独立求解器看生成答案，再检查答案一致性、解析/干扰项/评分点；检查结果绑定版本；人工明确批准，不自动批准；无 AI 时要求独立人工核对声明 |
| 题库与审核 | 所有者隔离、专门审核权限；原文定位、题目版本、检查报告和审核历史；停用阻断新组卷及导出；列表只携带当前版本，旧版在详情查看 |
| 组卷 | 选择已批准且依据有效的明确版本、排序/分值、草稿、复制、定版；冻结内容和评分点，题库编辑不改历史卷；学生视图使用服务端字段白名单 |
| 导出 | 学生/教师 DOCX、同模板 PDF 转换代码、教师 XLSX；XLSX 经用户同意使用已有 POI，仅写可信快照；每次下载鉴权并重新校验来源/题目状态 |
| 后台任务 | 持久队列、幂等、2 Worker、租约/心跳、逐槽位或逐批记录、取消、部分成功；不确定付费响应停止并等待确认，不自动重放；撤权/失租后不落库 |
| 管理界面 | 七个工作台页签、任务中心、错误状态、服务商/模型/预算确认、版本预览、私有下载、历史列表游标加载；测试夹具明确标识且与生产入口隔离 |
| 审计与持续检查 | 业务变更接入既有操作日志但不保存私有请求/响应正文；新增只读权限的 CI 测试/构建配置，未推送执行，不触发部署 |

自然语言入口是有意受限的本地规则工具，不是任意语义都能理解的模型规划器。模型适配目前仅接受 OpenAI-compatible HTTPS 文本接口；Anthropic 原生协议和 HTTP 本地模型没有实现。复杂公式、图片题、OCR、在线考试仍不在本期范围。

## 实际验证证据

全部输入均为自建合成资料。Java 集成测试使用 H2 MySQL 模式；另以独立 Docker MySQL 8、Redis 和完整 Spring Boot 应用执行真实 JWT 端到端验收，详见 [Docker 联调记录](ai-exam-docker-validation.md)。

| 验证 | 实际结果 |
|---|---|
| 命题模块 Java 测试 | 113 次用例执行通过（含测试类复用的流程用例，不是 113 个独立场景）；含 6 项不访问网络的真实适配层 HTTP 请求/响应契约测试 |
| 既有博客回归 | reactor 中实际执行 37 项，全部通过 |
| 前端 Node 测试 | 13 项通过：四题型、分值、学生白名单、缺失槽位、任务轮询/重试、幂等键、要求歧义 |
| 完整后端打包 | `ruoyi-admin -am` 成功；打包命令跳过测试，不能用它代替上一行测试证据 |
| 前端生产构建 | Vite build 成功；现有大包告警未视为通过性能测试 |
| 文档工作进程 | Python 3.12、python-docx 1.2.0、lxml 6.1.2、pypdf 6.16.2，8 项通过；含重复 ZIP、外链/DTD、文本框/删除内容排除、加密/扫描 PDF 拒绝、真实页码 |
| MySQL/JWT/Docker 接口链路 | 58 项检查通过：20 张命题表、四个迁移脚本重跑、菜单冲突、四账号登录、四题型人工审核定版、五种导出、文档解析、私有下载及撤权/来源版本门禁 |
| Docker 运行隔离 | 镜像实际构建并运行；容器内检查 UID 65534、无 capabilities、no-new-privileges、仅回环网络、只读根、临时区 noexec/nosuid、512 MB/无额外 swap/1 CPU/64 PID 限制 |
| DOCX/PDF 版式 | 四题型单页学生/教师卷、8 题长题干多页卷实际生成；使用文档渲染器和 Poppler 检查全部页面，核对中文、编号、页码和学生答案隔离；修复标题主题残留及简答作答区孤行 |
| XLSX | 四题型 POI 读回：数值分数、冻结窗格、答案解析、以公式字符开头的纯文本单元格；已用独立工具导入并检查左右两部分布局 |
| 浏览器 | 隔离只读夹具中检查七个页签、资料/引文、知识点编辑、题目录入、版本详情、人工审核表单、学生预览、要求解析和导出入口；发现并修复资料列表读取不存在题干字段的异常，刷新后未出现新的渲染错误。不是生产后端联调，未执行真实审批/下载 |
| 真实浏览器联调 | Vite 连接真实测试后端，普通命题账号登录、菜单加载、中文资料导入与片段确认成功；未授权外发，教师答案入口按权限隐藏；查看真实定版试卷与无答案学生预览。未将接口测试冒充逐项浏览器审批/下载测试 |
| 配置门禁 | 默认关闭时不创建命题数据库/Worker 组件；启用、关闭 Worker、缺少任务表时完整命题配置可以初始化；实际主应用旧数据库回归待执行 |

此外，P0 的 9 项 Java 兼容性探针、24 项协议测试和输入 PDF 视觉检查记录独立保留，不重复算成本轮新增测试。

重点覆盖：双所有者隔离、审核权限不等于批准权限、学生/教师分离、内容哈希和乐观锁、来源撤销、模型调用前撤权、超时不重试、失租取消、预算停止、长资料部分失败、重复上传、文件回滚补偿、导出结果写入与取消竞争、合并保留历史、停用题目及游标查询。

## 仍未通过的发布门禁

1. 用户存量库的备份恢复及列/索引差异审计、既有商城/博客界面全面回归。隔离初始化发现旧商城 `mall_phase_b_migrate_front_category.sql` 的 MySQL 1137 临时表重开错误；未修改它，命题联调跳过这段无关数据搬迁，不代表现有全量 Compose 初始化通过。
2. 工作进程/应用异常中断与恢复、真实磁盘满、峰值并发和长时间稳定性；当前已验证隔离配置实际生效及常规成功/失败路径，不等于完整压力或故障注入测试。
3. 更多领域、极限长内容与字体环境的打印样本验收；当前四题型单页及长题干多页样本已通过，复杂公式/图片/OCR 仍不支持。
4. 确认服务商、模型、费用上限和可外发资料；真实模型的结构化输出、提示注入反例、事实/解析质量、响应延迟和成本验证。当前只做模拟网关及本地 HTTP 协议拦截测试。
5. 领域审核者完成至少一轮样本评价、人工基线和试点结论；管理员确认留存/清理策略、备份恢复、镜像及系统依赖安全检查。

这些未决项保留为门禁，不能把所有开发计划复选框全部勾选。核心工程之外仍有后续增强：任意自然语言语义规划、知识点层级、全库语义查重、可视化自动归档和更大题库检索；当前采用受限规则、平面知识点、文本相似提示、人工留存管理和分页列表。

## 运行与维护

操作步骤、迁移顺序、权限、限制、命令和回退见 [运行与验收手册](ai-exam-runbook.md)。样例文件位于 `tmp/exam-mvp-qa/`，不是正式试卷；不应把整个 `tmp/`、测试依赖目录、输出目录或用户无关文档加入提交。

依赖选择参考维护者发布记录：[pypdf 版本](https://pypi.org/project/pypdf/)、[pypdf 安全公告](https://github.com/py-pdf/pypdf/security/advisories)、[lxml 版本](https://pypi.org/project/lxml/)。更新依赖和隔离运行降低风险，不代表完成独立安全审计。
