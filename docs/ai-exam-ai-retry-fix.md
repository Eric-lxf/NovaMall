# DeepSeek 输出截断与任务手动重试修复

日期：2026-09-03。开发分支：`codex/fix-exam-ai-retry`，基于 `master` 的 `451b358`。本记录说明本地实现和验证，不代表已经提交、合并或部署到生产环境。

## 修复内容

用户提供的任务记录显示 `finish_reason=length`，输出 4096 token 全部用于推理，知识点 JSON 未完成。原实现统一使用 4096 单次输出上限，未显式适配 DeepSeek V4 的默认思考模式。

- 知识点抽取：最多 4000 字符或 8 个资料片段为一批，提示每批最多 8 个简洁知识点；DeepSeek V4 显式关闭思考，默认单次输出 8192 token。
- 题目生成和独立复核：默认单次输出 16384 token；DeepSeek V4 显式启用 `low` 思考强度。截断结果仍拒绝入库，不通过拼接不完整 JSON 绕过校验。
- 单次输出参数同时用于调用、预算预留和模型配置快照，页面显示实际策略。提交和重试前按当前分批计划推荐总预算，用户可调整但不会自动追加。
- 仅对 `api.deepseek.com` 的 `deepseek-v4-*` 模型发送 DeepSeek 专用思考及 JSON 输出参数；其他兼容服务不混用参数，不更换用户所选供应商。
- 知识点抽取、生成、复核、资料解析、试卷导出支持手动重试。只重试未成功项，创建关联新任务，原结果和用量保留；旧版大批次失败任务可按新策略重新分批。
- 重试校验所有者、重试及业务权限、资料/题目状态、计划摘要和版本。AI 需重新授权及确认预算；执行结果不确定时额外确认风险，不自动再次调用。
- 服务端事务和幂等键防止重复创建后继。响应丢失后页面冻结原请求，使用相同键确认；不同请求键也不能对同一原任务重复创建后继。
- 文档解析重试复用原私有上传文件；导出重试建立独立导出记录。已保存成功项不重复导入或生成。
- 任务详情显示中文错误说明、原始错误码、调用结束原因，以及原任务/重试后继关联。

手动操作入口：**任务中心 → 重试**，或 **任务详情 → 手动重试未完成项**。已有直接重试后继时查看新任务；如果新任务再次失败，对新任务重试。基础自检仍使用原有最多运行三次的规则。

## 配置与发布

没有新增数据库表、列或 SQL 脚本；原有命题迁移和 `exam:task:retry` 权限需已就绪。更新前后端后才会出现新入口并使用新策略，运行中的旧容器不会因本地改代码而改变。

默认值和 ECS 配置方式见 [运行手册](ai-exam-runbook.md#deepseek-输出与思考预算2026-09-03-修复)。五个可选变量已贯通 GitHub Actions Variables、SSH、服务器环境文件、Compose 和 Spring；不设置时采用安全校验后的默认值。功能开关仍默认关闭，没有自动启用 AI 或修改真实模型配置。
